🎴 Tatami Match (畳マッチ)

A Japanese-themed memory card matching game built with HTML, CSS, and vanilla JavaScript.

___________________________________________________________________________________________

About

Tatami Match is a browser-based flip-and-match card game where players find pairs of matching Japanese-themed cards. The game tracks the number of moves taken, challenging players to complete it in as few moves as possible.

______________________________________________________________________________________________________________________________________________________________________________________________________________________________________

 How to Play

1. Open `index.html` in any modern web browser.
2. Read the fun fact on the start screen, then click **Start Game**.
3. Click any card to flip it and reveal the icon underneath.
4. Click a second card — if both cards show the same icon, they stay face up (matched!).
5. If the cards don't match, they flip back over after a short delay.
6. Keep going until all 4 pairs are matched.
7. Try to finish in as few moves as possible!

__________________________________________________________________________________________

 Features

- Start screen with a fun memory science fact
- Card shuffle on every new game so no two rounds are the same
- Move counter to track performance
- Win modal that displays your final move count
- Restart button available at any time
- Smooth animations — 3D card flip transitions and a pop-in modal effect
- Responsive layout — adapts to desktop, tablet, and mobile screens
